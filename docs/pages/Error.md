# Error.razor
Route: `/Error`
Popis: Obecná chybová stránka pro `UseExceptionHandler` v produkci, ukazuje Request ID.
Platforma: Web

## Hotovo ✅
- Stylovaná chybová karta, Request ID, odkaz na hlavní stránku

## Chybí / Rozpracováno ⚠️
- Radí uživateli zapnout `ASPNETCORE_ENVIRONMENT=Development` — to je rada pro vývojáře, ne pro hráče

## Návrhy na vylepšení 💡
- Tlačítko „zkopírovat Request ID“ pro nahlášení chyby
